# Jutsus de clã — catálogo de referência

Coleta de 30/10/2026 na academia de jutsus tipo=2. 320 técnicas com nomes, identificação do clã, graduação, requisitos textuais, URL original e arquivo de imagem. Todos os 320 registros têm imagem local. Pode haver reutilização da mesma arte por técnicas distintas; não representa 320 artes originais diferentes.

Arquivos: catalogo.json (dados e requisitos), catalogo.csv (lista tabular), nomes.txt (consulta rápida), imagens/ (arquivos nomeados com ID e técnica).

Este pacote cobre jutsus de clã. Não inclui ainda o catálogo completo de técnicas básicas, elementais, portões, karma, medicinais e kinjutsus.

Os arquivos foram coletados como referência; o download não concede licença para publicar ou reutilizar as artes no projeto.
